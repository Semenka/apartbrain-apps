# Apartbrain Home Assistant Apps

Privacy-first Home Assistant apps.

## Conversation Transcriber

Records audio from a USB microphone attached to a Home Assistant OS host,
transcribes it locally with Faster-Whisper, and sends weekly or on-demand
digests with authenticated links to full timestamped transcripts.

Recordings, transcripts, credentials, and Home Assistant configuration are
never stored in this repository.

Add this repository in **Settings → Apps → Install app → ⋮ → Repositories**:

```text
https://github.com/Semenka/apartbrain-apps
```
